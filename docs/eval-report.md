## Cost and tokens

- Tokens used in this run: 0 (the mock provider makes no API calls, so cost is $0).
- With a real provider, each `extract()` call stores the tokens the API reports in `provider.last_token_usage`, and ingestion writes it as `token_usage` in the `invoice_ingested` JSON log line, next to `invoice_id`, `provider`, and `elapsed_ms`.
- The APIs report prompt and completion tokens separately: OpenAI `usage.input_tokens` / `usage.output_tokens`, Anthropic `usage.input_tokens` / `usage.output_tokens`, Gemini `usage_metadata.prompt_token_count` / `candidates_token_count`. The app currently logs their sum. Summing `token_usage` across log lines and multiplying by the provider's per-token price gives the cost.

## Limits

- The mock is a parser written for this exact synthetic template, so these numbers show that the pipeline and scoring work. They are not a measure of real LLM accuracy.
- Real-provider accuracy needs an API key and is not run in tests or CI.
