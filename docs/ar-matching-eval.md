# AR cash-application (payment matching) eval

Generated by `scripts/eval_cash_application.py`. Every number below comes from that script.

- Matcher: `mock` (offline, deterministic; no API calls)
- Dataset: 15 synthetic bank payments scored against `data/ar/ground_truth.json`, which is read only after matching
- Scoring: status must equal the expected status (posted, needs_review, or unidentified). Applications must match the expected invoice numbers and amounts exactly. Leaving an unidentified payment unmatched counts as correct; guessing a customer or invoice counts as wrong.

- **Application accuracy:** 15/15 (100.0%)

## Limits

- **The mock scored 100%, and that is not a measure of real AI accuracy.** The mock is a deterministic parser written for these synthetic memo formats, and the fixtures were designed alongside it. The numbers show the rules, the auto-post threshold, and the review queue behave as specified.
- Real-provider matching needs an API key and is not run in tests, CI, or this eval.
